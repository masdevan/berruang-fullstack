# Berruang

A real-time chat room platform for connecting, communicating, and sharing conversations in a simple digital space.

## About

Berruang is a web-based chat room application built to provide a simple space for people to meet and communicate in real time.

The project is designed around shared digital spaces where users can join a room and participate in conversations.

## Features

- Real-time chat rooms
- Multiple users in a shared room
- Real-time messaging
- User authentication
- Responsive web interface
- Database-backed chat system
- Room-based conversations
